# BillPro

BillPro is a React single-page billing dashboard built with Vite, JavaScript, Tailwind CSS, React Router, and Lucide icons.

## Development

```bash
npm install
npm run start
```

Open `http://localhost:5173/` in your browser.

## Production build

```bash
npm run build
npm run preview
```

Routes include the home page, login, registration, dashboard, about, contact, terms, and privacy pages.
